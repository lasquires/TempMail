# tempMail

## Upload to GitHub Pages

Upload these three files to the root of the repository:

- `index.html`
- `app.css`
- `app.js`

In **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.

No build process, hidden files, folders, or GitHub Actions are required.

The current inbox is stored in the browser tab's session storage. It remains available while that tab is open. Closing the tab clears the locally stored credentials.
